NPX / COMMAND LINE

สำหรับเครื่องที่มี Node.js 18 ขึ้นไป คำสั่งจะดาวน์โหลด Installer ZIP ชุดเดียวกับปุ่มด้านบน และตรวจสอบ SHA-256 ก่อนเปิด Setup ทุกครั้ง 

npx --yes @robbygrean/jmoney-installer@latest install
npx --yes @robbygrean/jmoney-installer@latest update

ใช้คำสั่ง patch แทน update ได้ โดย Setup จะสำรองข้อมูลเดิมก่อนอัปเกรด

Important For Users

ถ้า Windows ขึ้นหน้าฟ้าเตือน ไม่ได้แปลว่าเครื่องเสีย

ตอนเปิดไฟล์ติดตั้ง Windows อาจขึ้นข้อความประมาณว่า “Windows protected your PC” เพราะแอปยังไม่ได้มีชื่อผู้เผยแพร่ที่ Windows รู้จักในวงกว้าง หน้าจอนี้เป็นการเตือนตามปกติของ Windows ไม่ใช่อาการไวรัสทำงานเองทันที

วิธีกดต่อแบบง่าย ๆ

  1. 1. เมื่อหน้าฟ้าเด้งขึ้นมา ให้มองหาปุ่ม More info
  2. 2. กด More info ก่อน
  3. 3. Windows จะโชว์รายละเอียดเพิ่ม และจะมีปุ่ม Run anyway
  4. 4. ถ้าคุณดาวน์โหลดไฟล์จากหน้านี้ ให้กด Run anyway เพื่อทำต่อ

คำอธิบายแบบภาษาคนทั่วไป

  • ถ้ายังไม่เห็นปุ่ม `Run anyway` ให้กด `More info` ก่อนเสมอ
  • หน้าต่างนี้เป็นการเตือนจาก Windows ว่าไฟล์ยังไม่เป็นที่รู้จัก ไม่ได้แปลว่าไฟล์นี้เปิดเองหรือทำลายเครื่องทันที
  • ถ้าโหลดจากแหล่งอื่นที่ไม่ใช่หน้านี้ หรือมีชื่อไฟล์แปลกไปจากที่ระบุไว้ ให้หยุดก่อนและอย่าเพิ่งกดต่อ
  • ไฟล์ที่ควรเปิดคือ `ReimbursementDocApp-Setup.exe` หลังแตก zip แล้ว

ถ้า Chrome เตือนว่าไฟล์ดาวน์โหลดน่าสงสัย

  1. 1. ตอนกดดาวน์โหลด Chrome อาจเตือนแบบนี้ได้ทั้ง Installer ZIP และ Source Code ZIP เพราะเป็นไฟล์ที่พัฒนาเองและยังไม่เป็นที่รู้จักในวงกว้าง
  2. 2. ให้คลิกเข้าไปที่รายการดาวน์โหลดนั้นก่อน แล้วมองหาปุ่มสำหรับดาวน์โหลดไฟล์ที่ถูกมองว่าน่าสงสัยต่อ
  3. 3. ถ้าคุณตั้งใจโหลดจากหน้านี้จริง ให้กดดาวน์โหลดต่อ แล้วไฟล์จะดำเนินการดาวน์โหลดต่อไปตามปกติ
  4. 4. ถ้าชื่อไฟล์ไม่ตรงกับ ReimbursementDocApp-Installer.zip หรือ ReimbursementDocApp-Source.zip ให้หยุดก่อน

What It Is

offline Windows app

local workflow

สำหรับผู้ใช้ทั่วไป

  • ติดตั้งแล้วใช้ในเครื่องได้ทันที
  • กรอกข้อมูลครั้งเดียวแล้วออกเอกสารหลายใบ
  • เก็บ output ไว้ในโฟลเดอร์ของโปรแกรม
  • เลือกเอกสารเป็นกลุ่มและสร้างตามงานที่ต้องการ

สำหรับคนที่อยากศึกษา

  • มี Source ZIP และ build scripts สำหรับตรวจสอบ
  • แยกข้อมูล, พจนานุกรม Tag และ catalog แม่แบบชัดเจน
  • มีชุดทดสอบเอกสารและการอัปเกรด installer
  • มี CHANGELOG และ release notes ที่ตรงกับรุ่นปัจจุบัน

Narrative ที่ต้องชัด

หน้านี้เป็น landing page สำหรับดาวน์โหลดโปรแกรมและศึกษาแนวคิดของระบบ แต่ตัวโปรแกรมจริงคือ WinForms app ที่รันในเครื่องผู้ใช้ ไม่ใช่ SaaS, ไม่ใช่ dashboard บนเว็บ

Architecture

แนวคิดระบบที่เอาไปใช้ซ้ำได้

Word template

ให้ layout อยู่ใน `.docx` แล้วใช้ code แทน `{tag}` แบบไม่ทำลายโครงหน้าเอกสาร

Master data JSON

เก็บข้อมูลอ้างอิงไว้ใน `app_database.json` เพื่อแยก business truth ออกจาก UI

User preset JSON

เก็บ preset ของผู้ใช้แยกจาก master data เพื่อรองรับงานรอบเดือนถัดไปแบบปลอดภัย

Offline packaging

ใช้ installer + payload + template folder เพื่อให้ workflow ใช้งานจริงในหน่วยงานได้ง่าย

Template Administration

กระบวนการเพิ่มเอกสารโดยไม่รบกวนผู้ใช้ทั่วไป

01

สร้างกลุ่มเอกสารและนำเข้าไฟล์ DOCX จากตำแหน่งที่ผู้ดูแลเลือก

02

ระบบคัดลอกต้นฉบับเข้า Template และสแกนแท็กในเนื้อหา Header และ Footer

03

กำหนด Custom Tag ที่พบใหม่ ตรวจวงเล็บและแท็กระบบที่จำเป็น แล้วทดลองสร้าง

04

เปิดใช้งานเมื่อผ่านเท่านั้น งานที่มีผลกระทบจะสร้าง backup และสามารถกู้คืนได้
